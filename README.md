# 30 Days of Code

Este repositorio contiene mis soluciones de los primeros desafíos de HackerRank, organizadas por día.

## Estructura
- Day 0: Hola, mundo y lectura de entrada.
- Day 1: Variables, enteros, dobles y cadenas.
- Day 2: Cálculo del total de una comida con propina e impuestos.

## Idiomas incluidos
- C#
- Python
- JavaScript
